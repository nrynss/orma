### The phase prose conflicts with the masking rule

The T2.8 block reads: "the dispatcher assembles the exact request body, writes
it to `call_events`, synthesises a terminal state from a chosen fixture, and
calls nobody." Its `Done when` line repeats the claim: "the recorded body
matches what live dispatch would send byte for byte". `AGENTS.md` forbids an
unmasked number and a secret in a sample, a log line or a document, and the run
owner may read `call_events`. The rule wins, so the recorded copy is a mask of
the assembled body. The body itself stays exact, the dispatcher compares it
byte for byte, and only the recorded copy is redacted. The landing commit should
say the dispatcher writes a masked copy of the body to `call_events`.

`_shared/events.ts` needs no change. Its comment already reads "Never put
secrets or unmasked numbers here", and the dry writer now honours it.
