decision belongs to the remediator.

## False positives I rejected

**Spelled-out numbers pass. "You completed eleven calls." returns an empty list.** The review
contract says every numeric token. "eleven" is not a numeric token. Prompt rule 1 orders numerals,
so digit scanning is the specified mechanism.

**A genuine fact number can serve any claim. The mood count 5 works as "5 calls".** The facts do
carry 5. The spec asks only that a prose number appear in the facts, and token-level checking
cannot bind a number to one field.

**"8:00" without the leading zero is rejected against a facts time of "08:00".** The prompt orders
verbatim copies, rejection fails closed, and retries stay bounded at three. Calling this a defect
rests on an unprovable guess about model output.

**The bare year 2026 is rejected.** Same copy rule and same fail-closed behavior as the time form.

**"88 percent" is rejected while the facts carry 0.88.** Rule 2 forbids conversion. The committed
suite pins a sentence of this shape as invalid by name. Intended.

**A transport error consumes no validation attempt and is never retried.** The contract requires
regenerating invalid prose. A transport failure is not invalid prose, and T7.2a pinned failure
propagation deliberately. The caller sees the throw and nothing is stored.

**The token exchange repeats on every attempt.** That cost lives in `_shared/vertex.ts`, reviewed
and approved under T7.2a. It buys one extra POST per retry and no correctness change.

**Comma tokens strip to bare integers, so "3,412" means 3412.** Documented intent, probed in both
directions above.
