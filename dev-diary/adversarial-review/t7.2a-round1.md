## Rejected false positives

**"vertex transcribe failed" became "vertex generateContent failed".** Deliberate rename for a
caller-agnostic shared client. No consumer reads the string. `captureVoiceNote` catches every
transcriber error and edits the ack to `VOICE_FAIL_TEXT` (`voice.ts` lines 196 to 206). A repo
grep finds no other reader and no suite pins the old message. No provable impact, so not a
finding.

**`bytesToBase64` now lives in both files.** Private in both, four lines, no URL or credential
semantics. `voice_vertex.ts` still needs it for the audio part. Exporting it would widen the
shared API against the minimality requirement.

**The suite never verifies the JWT signature cryptographically.** Header alg, payload iss, sub,
aud and scope, the three-part shape and the real RS256 sign path are all pinned. The synthetic
private key never leaves `testServiceAccountJson`, and only Google's token endpoint can complete
that check. Verification depth beyond this task's pin list.

**`testServiceAccountJson` is exported from a production module.** Pre-existing shape moved
verbatim, and the task text lists the service-account test key as something to move. It mints a
synthetic keypair per call, so it leaks nothing.

**The `!import.meta.main` gate could hide the tests.** Established repo convention, shared with
the voice suites. My standalone run counted 7 registered shared tests.
