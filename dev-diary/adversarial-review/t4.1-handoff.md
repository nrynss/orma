## Contract gaps (outside owns)

1. **Proxy path.** Spec wants `orma-api.nryn.dev/mcp`. Current proxy passes paths through unchanged. Function URL today is `/functions/v1/mcp`. Needs a rewrite outside T4.1 owns, or T4.3 docs the functions path.
2. **`verify_jwt`.** Default gateway verify may 401 before our handler. Clean protocol errors need `[functions.mcp] verify_jwt = false` in `supabase/config.toml`. That file is not in T4.1 owns.
3. **Tool bodies.** Full tool behaviour belongs to T4.2 under `mcp/tools/`. Stubs and the thin `list_items` select live in `index.ts` only for this transport pin.
