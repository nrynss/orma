# T3.1 contract change request

T3.1 owns only `supabase/functions/telegram/index.ts`. Two platform facts sit
outside that seam. This file records them so a later task can own the fix.

| Where | What | Pin | Mutation |
| --- | --- | --- | --- |
| `supabase/config.toml`, owned by T5.1 | Telegram posts webhooks with no JWT. This function must run with JWT verification off. T3.1 cannot write that file. | A deploy that still verifies JWTs returns 401 before `index.ts` runs. A forged POST never reaches the path-secret check. | A live message to `@orma_tele_bot` never arrives. Reviewers cannot pin secret rejection on the deployed function. |
| Deploy of `fn:telegram` | The function is not on the project yet. Deploy is an operator action, not a path T3.1 owns. | The functions list shows no `telegram` function until this entrypoint is deployed with JWT verification off. | The webhook URL from `ORMA_API_URL` 404s. Telegram cannot deliver updates. |

GET `${ORMA_API_URL}/functions/v1/telegram/${TELEGRAM_WEBHOOK_SECRET}` is how
this entrypoint registers `setWebhook` after deploy. It never uses a
`*.supabase.co` host.
