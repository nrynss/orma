# T3.5 contract change request

T3.5 owns only `supabase/functions/telegram/link.ts`. Linking helpers,
messages, and the store contract live there. Three other seams must call
those helpers. This task does not edit them.

Token hashes need a table. Profiles have `telegram_chat_id` but no token
column. A signed token without a consumed row cannot be single-use.

Minting and unlinking from Settings live in the web app. The bot `/start`
handler lives in T3.1 `index.ts`. Neither path is on the T3.5 owns line.

| Where | What | Pin | Mutation |
| --- | --- | --- | --- |
| New migration for `public.telegram_link_tokens`, outside T3.5 owns. Schema is frozen under T1.1. | Persist `token_hash`, `user_id`, `expires_at`, `consumed_at`. Unique on `token_hash`. RLS owner insert and delete. Service role consumes and binds. | `\d public.telegram_link_tokens` shows those columns. A second insert of the same hash fails. Anon cannot read another user's hash. | Without the table, `createRestLinkStore` cannot consume a token. Replay protection does not survive a cold isolate. |
| `supabase/functions/telegram/index.ts`, owned by T3.1 | `/start` with a payload must call `completeLink` and reply with `messageForLinkOutcome`. Bare `/start` keeps `START_LINK_PROMPT` from `link.ts`. | A `/start <fresh-token>` update leaves `profiles.telegram_chat_id` equal to the chat id. A second POST with the same token leaves that column unchanged. | T3.1 still replies with the placeholder on every `/start`. A deep-link press never binds. |
| `web/src/routes/app/settings/`, owned by T6.5 | Settings mints through `mintLinkToken` (or the same hash insert against the table) and unlinks through `unlinkTelegram`. Deep link is `telegramStartDeepLink`. | Settings shows `https://t.me/<bot>?start=<token>`. After unlink, `profiles.telegram_chat_id` is null and `telegram_link_tokens` has zero rows for that user. | The bot module can bind, but no user can mint or clear from the app. Done-when unlink from settings never runs. |
| `supabase/functions/_shared/database.types.ts` and `web/src/lib/database.types.ts`, owned by T1.3 | Regenerate after the token table lands. | Generated `telegram_link_tokens` Row includes `token_hash` and `consumed_at`. | Callers type against a table the generated file does not name. |
