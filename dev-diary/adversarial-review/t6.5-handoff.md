# T6.5 handoff: Settings and cancellation

Implementation role. This work is ready for independent review.

## What exists now

`/app/settings` is an owner-scoped browser view. It reads and updates the
profile, receipt preferences, consent rows, slots, scheduled runs, and the
existing Telegram link state under RLS.

- Profile settings cover name, phone, timezone, email receipts, and Telegram receipts.
- Consent can be granted after onboarding or revoked immediately. Revocation updates every live
  outbound-calls consent row, so the next dispatcher tick refuses calls.
- Slots can be added, edited, removed, paused, or resumed. Pausing sets every slot inactive.
- Each scheduled run whose `local_date` is today in the profile timezone has a cancellation
  control. It calls `cancel_call_run` and never writes `call_runs` directly.
- Account deletion requires typing `DELETE`, explains the cascade, calls `delete_my_account`,
  then signs the browser session out. It never deletes tables from the browser.
- The T5.3 Telegram Login Widget, bot-link refresh, mint, and unlink controls remain available.
