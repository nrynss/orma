## What I tried to falsify

**Inclusive window.** Run r13 sits on 08-31 and r14 on 09-08, one day outside each edge. Edge
mentions sit on the same two days. Widening either bound changes the mention and run counts.
Covered.

**Profile-timezone conversion.** Not covered. Finding 1. The fixtures cannot tell an Asia/Kolkata
date from a UTC date.

**Mention edges.** dentist owns four in-window mentions plus one on each edge day. physio owns
three. email Amma owns two. Reverting either bound lifts a count. Covered.

**Canceled-run exclusion.** r06 is canceled with disposition canceled. Mutation run D failed on the
morning rate exactly as the fixture predicts. Covered.

**Null-slot exclusion.** The short profile owns three null-slot runs and must return an empty
array. The inner join to slots also drops null slots on its own. Covered.

**Out-of-window retirement.** refuel scooter retires on 09-10. Including it gives retired_count 2
and average 37.0. The fixture pins 1 and 35.0. Covered.

**Future since_date clamp.** tax return reads minus 3 before the clamp. Removing `greatest` breaks
the ages equality. Covered.

**Two-day profile.** Three runs over two distinct dates, including a repeat. observed_days stays 2
and sufficiency stays false. Mutation run E also failed on distinctness. Covered.

**Empty profile.** Full object with empty arrays, null average, retired_count 0, sufficiency false.
Covered.

**Privileges.** All four roles checked. If a revoke named the wrong signature, PUBLIC would keep
the default execute grant and the public check would raise. The passing run pins the signature.
Covered.

## False positives I rejected

**observed_days counts 09-04, a day whose only run is canceled.** The contract defines no rule for
canceled-only days. The fixture and the SQL agree on one interpretation. Not a defect on this diff.

**answered_runs ignores state and filters disposition only.** The contract excludes canceled runs
only for slot rates. The fixture gives the canceled run disposition canceled, so nothing is proven
wrong. No contract breach.

**mood_distribution would count a canceled run with a non-null mood.** The contract says across the
period. The fixture pins no such row. No breach.

**The `where cr.slot_id is not null` clause is redundant with the inner join.** Redundancy alone is
not a defect. The short profile pins the behaviour either way.

**Random port collisions between concurrent harness runs.** The established T2.2 harness uses the
identical scheme. Convention and low probability. Not introduced here.

**Explicit fixture ids instead of generated ones.** Matches the established harness shape.
