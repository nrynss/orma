# T3.3 contract change request

T3.3 owns `supabase/functions/telegram/voice.ts` plus adapters
`voice_rest.ts`, `voice_telegram.ts`, `voice_vertex.ts` and Deno test modules
`voice_tests*.ts`. Ack, download, Vertex transcription, in-place edit, and the
storage insert helpers live there (`voice.ts` re-exports the adapters).

The webhook that receives voice updates lives in T3.1 `index.ts`.
`items` has no `audio_url` column. No Storage bucket exists in T1.1.
This task does not edit those seams.

| Where | What | Pin | Mutation |
| --- | --- | --- | --- |
| `supabase/functions/telegram/index.ts`, owned by T3.1 | A voice update must call `captureVoiceNote` with `createTelegramVoiceChat`, `createRestVoiceStore`, and `vertexTranscriberFromEnv`. Do that before any download or model call in the handler. Answer `voice_ok:` callback queries so Confirm does not spin. | POST a voice update from a chat whose `profiles.telegram_chat_id` matches. The first Bot API call is `sendMessage` with `VOICE_ACK_TEXT`. A later `editMessageText` targets that `message_id` and includes the transcript plus `voice_ok:<item-id>`. | Helpers exist, but a live voice note never acks, never transcribes, and never stores. |
| T3.1 `TelegramDeps` / `depsFromEnv` | Runtime must require `SUPABASE_SERVICE_ROLE_KEY`, `GEMINI_MODEL`, `GOOGLE_VERTEX_PROJECT`, `GOOGLE_VERTEX_LOCATION`, and `GOOGLE_APPLICATION_CREDENTIALS_JSON`. | `depsFromEnv` with any of those names unset throws `missing <name>`. Rest and Storage calls use `ORMA_API_URL`, never a project host. | The handler can parse a voice update and still cannot write an item or call Vertex. |
| New T1.1 migration for `items.audio_url` and bucket `item-audio` | Persist the Storage object URL on the item. Create private bucket `item-audio`. Owner read. Service role write. | `\\d public.items` shows `audio_url`. `insertVoiceItem` POST body includes `audio_url`. `POST /storage/v1/object/item-audio/<user>/<item>.ogg` with the service role stores bytes. | The rest adapter posts `audio_url` and an object path that the live schema and Storage reject. The item cannot carry a link. |
| `supabase/functions/_shared/database.types.ts` and `web/src/lib/database.types.ts`, owned by T1.3 | Regenerate after `audio_url` lands. | Generated `items` Row includes `audio_url`. | Callers type against a column the generated file does not name. |
