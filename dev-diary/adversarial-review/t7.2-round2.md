## False positives I rejected

- One verbatim quote licenses its digit run anywhere in the same prose, so quoting "renew 12
  month pass" also permits a later fabricated 12. Round 1 proposed exactly this design and left
  the decision to the remediator. The remediation diary documents it. Token-level checking cannot
  bind a number to one field.
- A date-shaped token inside item text can never validate, so quoting such an item verbatim fails
  closed and could exhaust retries. `4d8a70d` already checked dates before the numbers set, so
  the patch did not introduce this. It fails closed and needs speculative input.
- Comma tokens strip to bare integers, so "1,1" reads as 11. Round 1 adjudicated comma stripping
  as documented intent, and the prompt orders verbatim copies.
- Unpadded "8:00", the bare year 2026 and "88 percent" are rejected. Round 1 adjudicated these as
  intended fail-closed behaviour.
- A transport error consumes no validation attempt and is never retried. T7.2a pinned failure
  propagation deliberately, and the throw reaches the caller.
