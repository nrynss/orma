## Independent checks

`deno` was not on PATH. Deno 2.5.6 was installed only for this review.

`deno test --allow-net --allow-env --allow-read supabase/functions/telegram/index.ts` reported 4 passed, 0 failed.

A forged POST to `/functions/v1/telegram/wrong-secret` with a non-JSON body returned status 401 and an empty body. The fetch double was not called.

A POST to `/functions/v1/telegram` with no trailing secret returned status 401 and an empty body.

A GET to `/functions/v1/telegram/<secret>` captured setWebhook JSON whose `url` was `https://orma-api.nryn.dev/functions/v1/telegram/<secret>`. That URL did not contain `supabase.co`.

A GET to `/telegram/<secret>` (function-name prefix only) also registered. The captured `url` still used `ORMA_API_URL`, not a project host.

A POST `/start` with the path secret made grammY call `api.telegram.org`. The outgoing JSON `text` equalled `START_LINK_PROMPT`. The mock result text was a dummy `x`, so the pin is the outbound body, not the Bot API echo.

`depsFromEnv` with a getter that always returns `undefined` threw `missing TELEGRAM_BOT_TOKEN`.

`TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, and `ORMA_API_URL` appear in `scripts/bootstrap-env.sh` and `.github/workflows/_env-example.yml`. No values are committed.

A valid-secret POST with body `not-json` returned 500 and an empty body after a `getMe` fetch. That is outside T3.1 done-when. It is not recorded as a finding.
