## Independent checks

`npm --prefix web run types:check` compared a fresh linked-project generation
with both committed consumer files and passed. The two files are byte-identical.

An in-memory mutation of the `Json` declaration made the same generated stream
comparison exit 1. Drift detection therefore works when generation succeeds.

| Where | What | Pin | Mutation |
| --- | --- | --- | --- |
| `web/package.json` `types:generate` | The generator pipeline masks a failed `supabase gen` command because `tee` supplies the pipeline exit status. It exits 0 after replacing both consumer files with empty files. | In an isolated copy, a `supabase` executable that exits 1 made `npm --prefix <copy>/web run types:generate` exit 0. Both generated files measured zero bytes. | A network or authentication failure can erase both type contracts while reporting successful generation. The next `types:check` catches it, but only if someone remembers to run it. |
