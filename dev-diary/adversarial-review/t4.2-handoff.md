# T4.2 handoff

## What shipped
Six MCP tool handlers under `supabase/functions/mcp/tools/`.
`registerOrmaTools(server, client, user)` registers them all.
Handlers use the caller JWT client only. Never service role.

`add_item` writes `source = mcp`.
`set_slot` writes the slot directly for the authenticated caller.
`retire_item` sets status retired, `retired_at`, and `retired_reason`
starting with `mcp`. Response also names `retired_by` and
`retired_surface`. Web restore clears status and retired fields.

`get_patterns` returns the latest `pattern_reports` row with facts.
`get_last_call` returns the latest owned `call_runs` by `scheduled_for`.
