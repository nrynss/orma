# T2.6 remediation, round 1

This remediation addresses C1 and H1 from the capture-endpoint review. It does
not deploy the function or place a call.

| Finding | Remediation | Pin | Mutation covered |
| --- | --- | --- | --- |
| C1 | Replaced phone-only masking with schema-agnostic redaction. It retains JSON keys, nesting, arrays, scalar types and nulls, but replaces every string, number and boolean value. | `deno test --allow-env supabase/functions/calle-webhook/index.ts` verifies nested email, name, transcript text, E.164 phone and formatted phone values never enter capture evidence. It also checks the exact retained structure. | Restoring value logging leaks arbitrary provider payload data, including names, email, transcript text and phone formats the old pattern missed. |
| H1 | When capture logging throws after the receiver creates its de-duplication record, the handler removes that record and returns 500. A provider replay can then capture the evidence and record its id normally. | The same test command forces logging to fail, observes the scoped event-id delete, then replays the request and verifies the second capture succeeds. | Leaving the de-duplication record after a failed capture makes every provider retry a no-op and permanently loses the evidence. |

Validation also ran `deno check supabase/functions/calle-webhook/index.ts` and
`git diff --check`. Both passed.
