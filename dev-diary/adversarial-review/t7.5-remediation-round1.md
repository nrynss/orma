# T7.5 remediation round 1

## Verdict context

Round1 found one H. A CTA marker in user text killed the whole receipt,
because the guard refuses the composed body before anything else runs. This
remediation lands the prescribed fallback in the finalise receipt wrapper.

## Fix

`sendPostCallReceipt` now catches the refusal and retries once with no named
texts. The seam then sends its honest generic `Captured: none / Retired: none`
receipt. The retry reveals nothing and invents nothing. Any other failure
keeps the old silence. The refusal is thrown before the profile read and any
deliveries row, so the retry cannot duplicate a row. No path repeats ingestion
or un-finalises the run.
