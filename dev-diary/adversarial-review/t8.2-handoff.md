# T8.2 handoff: Keepalive and backup

## What landed

The keepalive workflow runs daily and on manual dispatch. It requires an exact 200 response from the API, dumps through the session pooler, validates a local restore, pushes to the private backup repository, and retains 14 dumps.

`restore-check.sh` restores one custom dump into an ephemeral network-isolated Postgres 17 container and prints public-table row counts.

## Safety and validation

The workflow uses explicit read-only `GITHUB_TOKEN` permissions. Backup repository writes use its separate fine-grained token. The dump never reaches logs, artifacts, or this repository.

Round 2 approved with zero findings. Its independent probes show that 204 and 302 fail the activity check, while 200 succeeds.
