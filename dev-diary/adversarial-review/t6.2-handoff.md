# T6.2 handoff: Items

Implementation role. This work is ready for independent review.

## What exists now

`/app/items` is a browser-rendered owner view under RLS. It reads the signed-in profile zone,
all of that owner's items, and `item_mentions` rows. It never derives a mention count from text.

- Add creates an item with `source: web` for the authenticated owner.
- Open items show the exact count of their mention rows and their age from `since_date`, falling
  back to `created_at` in the profile timezone.
- Details lets the owner set or clear `since_date`, then retire the item.
- Retire writes `status`, `retired_at`, and the explicit local reason. It never removes mentions.
- Retired items stay visible with their age and can be restored. Restore returns them to open and
  clears the local retirement fields without altering history.
