## The class, closed

Rounds 2 to 6 each found a fresh hole in this one helper, as a separator, a lift or a comment. The
enumerated separator rule was the root of the separator half. It is gone.

The rule is now category free. Two digits join when the gap between them holds at most four
characters, and a gap holds any code point that is not a decimal digit. So no code point category
can break a run, and the letter exclusion that produced finding one cannot come back through
another letter. The bound is what keeps digits from unrelated text apart. A gap of five characters
or more splits the run, which the comment states as an exclusion. The second exclusion is a run
shorter than seven digits, which the pattern never matched.

The timestamp rule is one condition. A stored timestamp keeps its digits only while every fragment
of its run holds seven or more digits. A zero digit fragment is too short, so a run of two stored
values masks whole. That is the change from the round-6 code, and it masks more, never less.
