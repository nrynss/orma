## Notes

- A briefing whose `open_items` is a string with no `- text (id: …)` lines lists nothing and reads "Nothing was open when Orma prepared this call.". `assemble_briefing` only ever writes item lines or `Nothing is open.`, so real data cannot reach this.
- A `retired_items` entry with a null offset maps to key `@0`. `result.ts` requires a numeric offset, and ingest casts it to an integer, so validated data cannot reach this.
