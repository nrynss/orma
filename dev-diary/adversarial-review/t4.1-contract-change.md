# T4.1 contract change requests

T4.1 owns only `supabase/functions/mcp/index.ts`. Two production seams sit outside that path.

## 1. Proxy rewrite for `/mcp`

Spec and PHASE-4 serve MCP at `orma-api.nryn.dev/mcp`.

The current `proxy/src/index.ts` rewrites the host only. Path `/mcp` therefore hits Supabase `/mcp`, not `/functions/v1/mcp`.

**Ask:** Either teach the proxy to map `/mcp` to `/functions/v1/mcp`, or amend the published URL in T4.3 to the functions path. Do not expand T4.1 owns into `proxy/`.

## 2. `verify_jwt` for function `mcp`

Missing or expired tokens must be clean auth errors from this handler.

If gateway `verify_jwt` stays true, anonymous clients may die at the edge before `index.ts` runs.

**Ask:** Add `[functions.mcp] verify_jwt = false` under a task that owns `supabase/config.toml`, or extend T4.1 owns to include that block only.

## 3. Tool files under `mcp/tools/`

T4.2 already owns `supabase/functions/mcp/tools/`. T4.1 keeps names and stubs in `index.ts`. No change requested. Recorded so review does not demand `tools/` writes here.
