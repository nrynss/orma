# T3.5 remediation round 1

This remediation addresses H, M, M, and L from `t3.5-round1.md`. It does not
change the verdict. T3.5 stays `claimed:orma`.

| Finding | Remediation | Pin | Mutation covered |
| --- | --- | --- | --- |
| H | `completeLink` still consumes first. A throwing `bindChatId` now calls `unmarkTokenConsumed`. Retry is not `replay`. Taken and missing still consume. | `deno test --allow-read supabase/functions/telegram/link.ts`. New test replaces `bindChatId` with a throw. `consumedAt` stays null. Chat stays null. A second `completeLink` with the working bind returns `bound`. | Restoring consume-before-bind without rollback burns the Start payload on one failed profiles PATCH. The replay test still passes. |
| M | Mint serializes per user. The store replaces open tokens in `replaceOpenTokenForUser`. Memory insert also drops other open hashes for that user. | Same Deno file. `Promise.all` of two mints with distinct 32-byte entropy. `findToken` reports exactly one live row with `consumedAt` null. | Dropping the replace and the per-user lock lets Settings double-submit keep two deep links. The second `/start` can move `telegram_chat_id`. |
| M | `unlinkTelegram` deletes tokens first, then clears the chat. A throwing delete never reaches `clearChatId`. | Same Deno file. `deleteTokensForUser` throws. Unlink throws. `telegramChatId` stays the bound chat. `findToken` still returns the leftover hash. Chat is not null while that hash is live. | Clearing chat first lets a failed delete look unlinked. The leftover token can then bind a new chat. |
| L | `mintLinkToken` requires `entropy.length === LINK_TOKEN_BYTES`. Shorter entropy throws before encode. | Same Deno file. `entropy: new Uint8Array([1])` throws. `completeLink` of payload `AQ` does not return `bound`. | Removing the length check lets a caller mint a guessable `?start=` payload.
