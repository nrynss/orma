## Done when, clause by clause

Quoted from `dev-diary/PHASE-9-ui.md` section T9.1.

1. **"every page still builds and passes `npm run check` on the new tokens alone"**.
   Satisfied, with the gate taken as given. The main agent ran it on this tree and reported
   338 files, 0 errors and 0 warnings, and `npm run build` succeeded. I add one more piece
   of evidence. The delta changes no page file, no loader, no model and no query, so a
   green check was not bought by editing a page.
2. **"the gallery shows every component in light and dark"**. Satisfied for coverage, with
   F1 as the exception in what one component actually shows. Both panes hold all 12
   components, 38 component elements each, at 1280 and 360 wide. No element has a zero
   width or height. All 57 declared tokens appear in each pane. The AppNav, Button, Card,
   Badge, Stat, SectionHeader, Field, Switch, EmptyState, ItemLine and MoodMarker render
   with their text, and the Switch flips `aria-checked` when I clicked it.
3. **"the gallery 404s in production"**. Satisfied, pinned twice from the built output.
   `wrangler dev` on `.svelte-kit/cloudflare/_worker.js` answers `HTTP/1.1 404 Not Found`
   with a 3549 byte error page whose text reads "404 Not found", and no gallery markup.
   `vite preview` answers the same. `/` and `/login` answer 200 in the same server. The
   guard is the `dev` constant and not an environment variable: the build folds
   `web/src/routes/dev/ui/+page.ts` to `var load = () => { error(404, "Not found") }`, and
   the client node chunk carries the same 404.
4. **"every text token pair meets AA contrast by measurement"**. Satisfied. I recomputed
   142 pairs from the hex values in `tokens.css`. Every text pair clears 4.5 to 1. The
   worst real pairing is `--danger` on `--danger-soft` in light at 5.59 to 1. The worst in
   the whole sweep is `--warning` on `--brand-soft` in light at 5.43 to 1, which no
   component uses. The tightest non text pair is `--border-strong` against
   `--surface-raised` in dark at 3.05 to 1, which clears the 3.0 floor.
