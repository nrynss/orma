## Judgement, why this scores on this commit

Two prior rounds noted the guard and declined to score it. `t7.4-round1.md`
recorded that a question mark would throw while the seam still had no
production text. `p7-e2e-round1.md` rejected the same item because the path had
no production caller, and named the exposure as live once that finding was
fixed. This commit is that fix. The deferred exposure is now production
behaviour, so the item transfers to this round.

The repository's own precedent agrees. The pattern channel passes
`enforceNoCta` false because its prose is owned outside the seam, a change
`t3.4-contract-change.md` records. Post-call content is now owned by users and
by the transcript in the same way. The wiring hands exactly that kind of
content to the all-or-nothing guard.

## False positives I rejected

- **A rejected Telegram fetch writes its error message into
  `deliveries.error`, and a fetch rejection message carries the URL with the
  bot token.** True of the seam, landed in T3.4 and byte-identical here. The
  diff's own log path only sees thrown errors, whose messages on this wiring
  are fixed strings or front-door URLs with no key. Residue against the seam,
  not a finding on this diff.
- **The resolver reads items one request per id.** The same serial shape was
  adjudicated unprovable in the T7.3 round and matches the profile loop in
  analysis.
- **Tick now fails startup without `TELEGRAM_BOT_TOKEN`.** That is the
  prescribed named-env failure. The name predates this task in `.env.example`,
  `.github/workflows/_env-example.yml` and `scripts/bootstrap-env.sh` since
  T3.1, and the deployed telegram function already required it.
- **The calle owns line reads field only while the patch threads the env
  name.** The e2e fix shape and this round's brief both prescribe exactly that
  threading, so no owns breach stands.
- **A lost finalised append loses the receipt with it.** Deliberate ordering.
  The receipt follows the append so an unaccounted run never receipted, and a
  lost append is already named on the run row.
- **No fetch timeout anywhere on the receipt path.** A codebase-wide
  pre-existing convention, unchanged by this diff.
- **A skipped receipt is silent.** The seam's documented design. Prefer silence
  over an audit row, and the wiring rightly leaves the skip inside the seam.
