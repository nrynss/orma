## The shape of the fix

Two rules decided every repair.

**One unusable entry costs only that entry.** `ingestTerminalRun` now repairs the extraction entry by
entry instead of nulling the whole result. A commitment whose `due` is free text keeps its row with a
null `due`, because the caller did make a commitment and the transcript still holds the words. A
retirement or a commitment that names an unknown item is dropped. Every drop is named in a new RPC
argument, `p_skipped`, and that list lands in the run's `ingested` timeline row.

**Everything the RPC would raise on is repaired before the request leaves.** The RPC still raises on
bad input, and case seven still proves that for all 18 values. The repair belongs in the caller.

## Contract change, and the shared stack

`ingest_call_result` gained a twelfth argument, `p_skipped jsonb default '[]'::jsonb`. The default keeps
every existing caller working, and test-ingest.sh still calls it with eleven arguments. Ingestion now
writes the `ingested` row, which the batch contract permits for a SQL function that inserts the same
shape.

The exported names and shapes of `ingest.ts` are unchanged: `TerminalCallSource`, `IngestDeps`,
`IngestResult`, `depsFromEnv` and `ingestTerminalRun(source, deps)`. `dispatch-mode.ts` types its seam
the same way it did, and `calle.ts` checks against the new module. Nothing needed a widen, so nothing
was widened, and `slotChangeRequested` still returns the proposal.

The eleven-argument function was dropped from the shared stack and the new one created, then PostgREST
was told to reload its schema. `database.types.ts` under `supabase/functions/_shared/` and under
`web/src/lib/` carries a `Functions` block, so it may need one regeneration. T25aImplement owns both
files and was told.
